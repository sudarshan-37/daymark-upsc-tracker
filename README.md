# Daymark UPSC Daily Tracker

Static website files for deployment with GitHub Pages.

## Publish

1. Upload the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set the Pages source to **Deploy from a branch**, select the default branch and `/ (root)`, then save.

GitHub Pages will provide the published site URL after deployment completes.

## Data and accounts

This static demo stores account records, tasks, notes, and reminder settings in each visitor's browser. It does not verify email addresses or phone numbers, sync data, or provide server-backed authentication. Browser notifications work only while the page is open and permission is granted.
